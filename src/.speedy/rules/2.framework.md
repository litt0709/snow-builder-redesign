# Khung Thực Thi AI-DD Trong Speedy

## 1. Các Chế Độ Định Tuyến (`Flow Mode`)

| Mode | Điều kiện áp dụng | Chuỗi thực thi |
|---|---|---|
| `setup` | Dự án đã có code nhưng chưa khởi tạo `ai-workspace/state/setup.json` | Kiểm tra môi trường → Scan → Sinh tài liệu nền & rules |
| `feature` | Tính năng mới hoặc thay đổi hành vi/interface/kiến trúc | Bootstrap → Analyst → Architect → Implementer → Reviewer → Tester → Docs → Wrap-up |
| `fix` | Sửa lỗi / regression | Bootstrap → Root Cause Pre-flight → Analyst → Architect → Implementer → Reviewer → Tester → Docs → Wrap-up |
| `simple` | Chỉnh sửa nhỏ 1 file cấu hình/văn bản an toàn, không đổi logic/API/schema/auth | Bootstrap → Duyệt Scope → Implementer → Kiểm tra phù hợp → Wrap-up |
| `verify` | Kiểm tra mã nguồn đã có so với yêu cầu (không sửa code) | Bootstrap → Xác nhận Scope → Reviewer → Tester (tùy chọn) → Verify Report → Wrap-up |

## 2. Chế Độ Gate (`strict` vs `balanced`)

- **`strict` (mặc định)**: Dừng chờ người dùng chọn `Approve / Request Changes / Abort` tại mỗi stage chuyên môn.
- **`balanced` (chỉ bật khi người dùng cấu hình tường minh)**: Tự chuyển qua các bước rủi ro thấp khi Handoff Validator và Verification đều đạt, nhưng luôn dừng hỏi ở thay đổi kiến trúc, mở rộng scope, xóa dữ liệu hoặc thao tác Git/release.
